# Security and rights reports

Please do not open a public issue containing credentials, private correspondence, restricted data, or a takedown concern.

For a suspected exposure, contact the repository owner privately with:

- the affected path or commit;
- the kind of material involved;
- whether the material is still accessible elsewhere;
- any requested containment deadline.

If the issue involves a third-party right, include the relevant permission or notice if you have one. Do not upload the disputed file to demonstrate the problem.
